# Student Attendance System

## Project Description
The Student Attendance System is a C# Windows Forms application designed to help a school manage student information and attendance records. It aims to make common attendance tasks easier to organize and track.

## Main Features
- Administrator login
- Add, edit, and delete student records
- Search and filter students
- Record student attendance (present/absent)
- View attendance statistics
- Export data to CSV
- Activity log and password settings
